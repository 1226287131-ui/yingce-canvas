# 用户自定义 API

用户在「账户与设置 → 个人渠道」添加自己的上游地址、认证信息、协议和模型，再在「模型与能力」配置文本、图片、视频或音频能力，最后从各功能的模型选择器选用。普通生成、工作台、智能创作、图片转预演和画布 Agent 使用同一份个人模型配置。管理员的自定义渠道开关仍然控制准入；系统模型继续使用后台渠道和原有计费。

API 地址可以包含网关路径和固定查询参数。追加模型接口时保留已有参数，接口指定的同名参数优先，URL fragment 不发送。插件文本和编辑器助手沿用相同的个人渠道配置；RunningHub 使用其独立工作流配置，同样支持带查询参数的网关地址。

## Agent 和媒体工具

创建或续接 Agent 时，客户端提交 `customModelId` 和 `customModels`。目录项为 `{ id, name, capability, config }`；`config` 使用普通生成的 provider 合同，包括 `baseUrl`、`apiKey`、`secretKey`、`headers`、`interfaceType`、`apiFormat`、`model`、`capabilityConfig` 和 `defaultOptions`。目录最多 128 项，只提交当前启用的用户模型，主模型必须为文本能力。

目录是当前用户当前轮的授权快照。Agent 的模型目录和媒体工具只接收 `custom:<id>` 选择器及模型名称，不接收连接地址、Header 或密钥。生成前检查目录归属、能力、参数、资源归属、权限和预算；审批可在本轮已授权的模型中改选。自定义生成使用原有任务队列、媒体保存和幂等流程，不预留或扣除平台模型积分；上游服务商仍可能收费。

请求快照随任务保存，并用于工具执行、续聊、上下文压缩和重启恢复。个人记忆压缩也可选择用户文本模型；定时压缩仅保存所选模型的加密配置。管理员关闭个人渠道后，新任务和记忆压缩继续受开关限制。

## 时间线字幕

时间线转写可选择支持 OpenAI-compatible `/audio/transcriptions` 的个人模型，后端以 multipart 提交原有用户音频资源，并设置 `response_format=verbose_json` 和 `timestamp_granularities[]=segment`。上游必须返回包含时间戳的非空 `segments`。未选择个人模型时沿用部署配置的 Whisper 服务。普通语音生成模型不必然支持转写，应填写上游实际支持的模型名称和接口协议。

## 凭据与部署边界

请求通过本站登录态和 HTTPS 发送至后端，由后端访问上游。任务、Agent 执行快照、智能创作提交和个人记忆设置中的连接地址、API Key、Secret Key 和自定义 Header 值使用现有 `.settings-key` 加密，不进入分享画布。备份数据库时必须一并备份该文件；丢失它会使排队和定时任务无法解密。

浏览器调用经本站中转，上游鉴权不会拼入本站请求 URL；跨源产物链接不会继承网关查询参数。

浏览器 pending Agent 记录仅保存不含凭据的请求和 SHA-256 摘要。重试时从当前个人配置重建快照，摘要不匹配就停止重放，避免把不同配置复用为同一幂等请求。

出站访问继续使用 SSRF 校验，默认拒绝本机、内网和链路本地地址。私有网关只能通过 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 精确允许目标主机。支持范围取决于所选协议和上游能力；任意 HTTP 接口不会自动成为兼容的模型接口。

本功能需前后端一同发布并升级 schema 58。源码定制部署应停用官方 Host Updater，避免更新覆盖定制实现；后续升级先合并上游变更并重新验证。回退旧后端必须恢复匹配的 schema 57 备份，不能只切换镜像。
